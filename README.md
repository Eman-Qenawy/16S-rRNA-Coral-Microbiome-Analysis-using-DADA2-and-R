Coral Microbiome Analysis Using DADA2

Overview

This project analyzes 16S rRNA sequencing data from healthy and bleached coral samples from the Northern Red Sea.

The analysis was performed using the DADA2 pipeline in R to investigate sequencing quality and microbial community composition.

Objectives

- Assess the quality of 16S rRNA sequencing data.
- Evaluate sequencing error rates.
- Process sequencing reads using DADA2.
- Generate Amplicon Sequence Variant (ASV) tables.
- Generate taxonomic classification tables.
- Compare microbial communities between healthy and bleached corals.
- Explore microbial community diversity.

Analysis Workflow

1. Quality Control

Sequencing quality profiles were examined for forward and reverse reads.

2. Error Rate Assessment

Error rates were evaluated for the sequencing reads as part of the DADA2 workflow.

3. DADA2 Processing

The sequencing data were processed using DADA2 in R to obtain high-quality amplicon sequence variants.

4. ASV and Taxonomy Tables

ASV and taxonomy tables were generated for downstream microbiome analysis.

5. Diversity Analysis

Alpha and beta diversity analyses were performed to characterize and compare microbial communities between healthy and bleached coral samples.

6. Visualization

Plots were generated to visualize sequencing quality, error rates, and microbiome analysis results.
